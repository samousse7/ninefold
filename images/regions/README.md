# Region backgrounds

One background per region, shown behind the board during duels and on the screen before a duel.
Use a wide image (16:9). Keep the middle calm: the board covers it. The game darkens the image a little so cards stay readable.
Any name works: "Ashgrove Academy.png" becomes `ashgrove-academy.jpg` automatically. Regions without a background keep the night sky.

- `ashgrove-academy.jpg`  Ashgrove Academy
- `port-ravel.jpg`  Port Ravel
- `dustmaw-prison.jpg`  Dustmaw Prison
- `frostpine-monastery.jpg`  Frostpine Monastery
