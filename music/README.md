# Music

Upload the game's background tracks here with exactly these names (MP3, or WAV/M4A which are converted to MP3).
The GitHub Action compresses them automatically and adds them to the offline copy of the game.
Any track that is missing is skipped: boss duels fall back to the region track,
and a region falls back to the title track.

| File | Plays during |
|---|---|
| title.mp3 | Title screen, map, deck, shop, album, menus |
| ashgrove.mp3 | Ashgrove Academy duels |
| port-ravel.mp3 | Port Ravel duels |
| dustmaw.mp3 | Dustmaw Prison duels |
| frostpine.mp3 | Frostpine Monastery duels |
| aurum.mp3 | Aurum, the Floating City duels |
| shattered-isle.mp3 | The Shattered Isle duels |
| citadel.mp3 | The Citadel of Ages duels |
| boss.mp3 | Boss duels in every region |
| victory.mp3 | Short jingle after a win |
| defeat.mp3 | Short jingle after a loss |
